# Smart Home Calc

Рабочая первая версия по Professional Developer Specification v3.0: React + TypeScript + Tailwind CSS, FastAPI, SQLite в автономной Windows-сборке и PostgreSQL в среде разработки.

## Дизайн-система

Единые токены, компоненты и правила экранов: [Smart Home Calc 1.1](design-system/smart-home-calc/MASTER.md).
Офлайн-образец создаётся командой `npm run design-system:preview --prefix frontend`; токены проверяются через `python scripts/build-design-tokens.py --check`.

## Запуск через EXE на Windows

1. Откройте страницу [Releases](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/latest) и скачайте `SmartHomeCalc-Windows-x64.exe` из раздела **Assets**.
2. Запустите EXE двойным щелчком. Smart Home Calc распакует локальные компоненты и откроется как отдельное Windows-приложение.

Docker, Python и PostgreSQL устанавливать не требуется. EXE содержит интерфейс и локальный сервер, а встроенная SQLite хранится в `%LOCALAPPDATA%\SmartHomeCalc\data\smart-home-calc.db`. PDF и изображения находятся в `%LOCALAPPDATA%\SmartHomeCalc\data\storage`. Повторный запуск EXE сохраняет все данные.

EXE запускает собственное окно со встроенным системным компонентом WebView2. Microsoft Edge, Chrome или браузер по умолчанию не открываются. Интернет для работы не нужен: интерфейс, сервер и SQLite работают на этом же компьютере. WebView2 Runtime входит в Windows 11 и большинство актуальных установок Windows 10; если компонент удалён, его потребуется установить отдельно.

Файл собран без коммерческой цифровой подписи. Windows SmartScreen может показать предупреждение: проверьте имя файла и контрольную сумму релиза, затем выберите **Подробнее → Выполнить в любом случае**. Приложение не открывает сетевые порты наружу и работает через `localhost`.

## Если запуск зависает при включённом VPN

Начиная с v1.0.36 проверка готовности локального сервера и окно WebView2 подключаются напрямую, без системного HTTP-прокси. VPN и настройки Windows приложение не изменяет. Если VPN дополнительно блокирует соединения с `127.0.0.1`, разрешите локальный доступ в его настройках.

Закройте Smart Home Calc перед запуском нового EXE. Проекты остаются в прежней папке `data`; переносить или удалять её для обновления не нужно. Этапы запуска и ошибки окна записываются в `%LOCALAPPDATA%\SmartHomeCalc\data\desktop.log`, серверные сообщения — в `server.log` в той же папке. При ошибке приложите оба файла. Подключение к серверу ограничено 90 секундами, каждый этап создания WebView2 — 45 секундами; вместо бесконечного ожидания появляется сообщение об ошибке.

## Перенос на другой компьютер

Откройте **Настройки → Открыть папку данных**: Проводник сразу покажет хранилище всех проектов. Для переноса всех проектов и полного каталога автономной Windows-версии закройте приложение и скопируйте **всю папку `%LOCALAPPDATA%\SmartHomeCalc\data`**, включая `smart-home-calc.db` и `storage`. На новом ПК установите v1.0.25 или новее и замените папку данных при закрытом приложении. Пути к PDF перепривязываются автоматически. Если на новом ПК уже есть нужные данные, предварительно сохраните их: полная копия заменяет базу, а не объединяет её.

[Пошаговая инструкция переноса и состав резервных копий](docs/transfer-windows.md). ZIP отдельного проекта не содержит неиспользуемые позиции общего каталога.

## Спецификации в PDF и Excel

- PDF — альбомный A4: таблицы по помещениям с повторением заголовков, переносом длинных описаний, количеством, единицами, ценой, валютой и суммой. В помещениях — количество каждой позиции; отдельный итог помещения выводится только для электроустановок и рамок. Общий итог всех посчитанных позиций находится в конце отчёта, отдельно по штукам и метрам. Пустые категории скрыты; суммы по валютам и рекомендации IP сохранены.
- Excel — адаптивные листы «Итоги» и «Итоги по помещениям», общая ведомость, сгруппированная ведомость «По помещениям», листы по категориям и проверки IP. Заголовки закреплены, в таблицах есть фильтры, чередование строк, перенос текста и числовые форматы. Настроена печать подробных ведомостей на альбомном A3, итогов — на A4.
- Характеристики подписаны по-русски вместо JSON. Стоимость разных валют считается отдельно; метраж и количество оборудования не складываются в один показатель.

## Коммерческие предложения

КП можно создать без проекта: **Все КП → ＋ Создать КП без проекта**. Доступны те же товары, фотографии, скидки, импорт документов и оба PDF. Самостоятельное КП сохраняется в общем списке и не создаёт скрытого проекта. **Прикрепить к проекту** переносит его целиком в выбранный проект; если у проекта уже есть КП, прежний документ автоматически сохраняется в списке «КП без проекта». При привязке цены и содержимое КП сохраняются, а позиции плана остаются прежними. Расчёт проекта можно добавить позже кнопкой «Обновить из расчёта». Полный перенос папки данных включает все самостоятельные КП.

Откройте проект и вкладку **КП**. При первом открытии редактор переносит посчитанные позиции, количество и уже назначенные товары. **Обновить из расчёта** обновляет эти строки без дубликатов; ручные строки и индивидуальные скидки сохраняются. Изменения КП сохраняются кнопкой **Сохранить КП**, а перед выгрузкой PDF сохраняются автоматически.

- Выберите товар в строке КП либо нажмите **＋ Товар в базу**. Новый товар, артикул, производитель, цена и фотография попадут в общий каталог; товар привяжется ко всем объектам этой строки на плане. Заблокированный слой сначала нужно разблокировать. Для рассчитанной рамки товар хранится в КП.
- Цена, реквизиты, фотографии, номер, дата, срок действия, примечание о НДС и условия предложения редактируются в КП. Изменение цены строки КП не переписывает цену товара в общем каталоге.
- Общая скидка действует на все строки без индивидуальной скидки. Скидка строки заменяет общую; **0%** исключает строку из общей скидки, пустое поле возвращает общую.
- **PDF для клиента — без скидок** использует исходные цены и не выводит скидочные колонки. **PDF для партнёра — со скидками** применяет настроенные скидки. Валюты считаются отдельно, округление денежных значений — до копеек.
- PDF выполнен в стиле предоставленного референса: тёмная шапка, зелёный итог, срок действия, фотографии товаров и контакты. Логотип и реквизиты можно заменить в разделе **Оформление и реквизиты**.
- **Импорт из PDF / Excel / Word** читает PDF с текстовым слоем, Excel `.xlsx`/`.xls`/`.xlsm`, Word `.docx` и CSV. В таблице нужны заголовки наименования, цены и количества. Перед переносом проверьте распознанные строки; можно добавить их к текущему КП или заменить позиции. Импортированные количество и цены остаются редактируемыми.
- Скан PDF нужно предварительно распознать; старый Word `.doc` — сохранить как `.docx`. Файл — до 20 МБ, PDF — до 100 страниц, КП — до 5000 строк. Формулы и макросы не выполняются: для Excel нужны сохранённые значения ячеек.
- КП входит в полную папку данных и ZIP-копию проекта. При восстановлении связи с товарами и объектами плана перепривязываются.

## Возможности

- В библиотеке выберите группу: силовые и слаботочные розетки; обычные, проходные, перекрёстные и звонковые выключатели; диммеры; терморегуляторы; сценарные кнопки; заглушки; выводы кабеля. «Все группы» показывает полный список с разделами. Такие же группы есть в каталоге, выборе типа товара и замене номенклатуры объекта. USB-розетка «2 в 1» относится к силовым, отдельные USB, TV, RJ45 и HDMI — к слаботочным.
- «Заглушка» и «Вывод кабеля» размещаются на плане как штучные электроустановочные изделия, входят в рамки, ведомости PDF/Excel и резервные копии проектов. Обновление добавляет их в существующий каталог автоматически.
- Чтобы убрать завершённый проект или случайный дубль, выберите его в списке и нажмите «Удалить проект». В окне подтверждения проверьте имя; при необходимости сначала скачайте ZIP-копию. «Удалить навсегда» удаляет весь проект вместе с его PDF, разметкой и расчётами, даже при заблокированных слоях. Общий каталог и другие проекты сохраняются. Удаление проекта через Ctrl+Z не отменяется; сохранённую ZIP-копию можно восстановить кнопкой «Восстановить ZIP».
- Перетащите PDF из Проводника в любую часть окна калькулятора, задайте имя и создайте новый проект со всеми страницами. Имя по умолчанию берётся из файла; до подтверждения проект не создаётся. При ошибке PDF пустого проекта не остаётся. Кнопка «Новый из PDF» открывает тот же импорт через выбор файла. Кнопка «Загрузить PDF» справа добавляет страницы в уже открытый проект.
- Кнопка с шестерёнкой «Настройки» открывает папку всех данных Windows-приложения в Проводнике и показывает инструкцию полного переноса. Копируйте папку `data` целиком при закрытом калькуляторе.

- Создание проектов и помещений, признак влажной зоны. Помещение можно очертить вогнутым полигоном до 1000 вершин, точно повторяя выступы и ниши. При редактировании видны все контуры текущего листа; вершины перетаскиваются, новые добавляются на ближайшее ребро или его середину, доступна привязка углов и Shift для прямых стен. Ранее и позднее добавленные элементы внутри автоматически получают это помещение.
- Загрузка PDF до 500 МБ и 100 страниц; каждая страница — отдельный рабочий лист. Большие файлы записываются потоково, без загрузки целиком в оперативную память. Просмотр растровой копии, масштабирование, прокрутка и перетаскивание плана средней кнопкой мыши.
- Справа собраны все инструменты слоёв и страниц: выбор активного слоя, видимость, блокировка, включение в ведомость, создание слоя, загрузка/переименование PDF и настройка наложений. Слева — библиотека, размещение, рамки и свойства объектов. Список «Слои элементов» по умолчанию свёрнут; стрелка справа от заголовка раскрывает и сворачивает его. Панели можно скрывать независимо.
- Размещение, перетаскивание, редактирование и удаление элементов. Координаты нормализованы в диапазон 0–1 и сохраняются в локальной базе данных.
- Выделенный объект подсвечивается контрастным пульсирующим ореолом. Щелчок по его названию в свойствах центрирует объект на плане, двойной щелчок по названию или обозначению выбирает все объекты той же номенклатуры.
- Свойства объекта сохраняются автоматически. `Ctrl+Z` отменяет точки незавершённых линий и контуров, изменения вершин и до 50 сохранённых действий в текущем сеансе: размещение, перемещение, удаление объектов, рамки, помещения, настройки слоёв и наложения, калибровку с пересчётом длин. `Ctrl+Y` и `Ctrl+Shift+Z` возвращают отменённое. В текстовых полях сохраняется обычная отмена ввода; удаление PDF-страниц остаётся необратимым и очищает историю.
- `F7` или кнопка «Скрыть элементы» временно скрывает всю разметку для просмотра чистого PDF-плана; повторное нажатие возвращает её.
- `Ctrl + колесо` изменяет только масштаб плана под курсором и не масштабирует интерфейс приложения. Выбранный размер обозначений запоминается отдельно для каждого проекта на этом компьютере.
- Номенклатуру уже размещённого объекта можно заменить в панели свойств без повторной установки точки: координаты, помещение и комментарий сохраняются, несовместимая привязка к товару сбрасывается.
- Редактор плана и спецификация открываются в отдельных вкладках. В редакторе лист и обе боковые панели прокручиваются независимо, поэтому рабочие инструменты не уезжают за пределы окна.
- Правый щелчок по объекту или группе выделенных объектов открывает меню свойств, назначения/снятия рамки, удаления и снятия выделения.
- При выборе ЭУИ через `Ctrl + щелчок`, рамкой или двойным щелчком количество постов автоматически синхронизируется с количеством выбранных объектов (от 1 до 6).
- Левую и правую панели можно независимо скрыть, освобождая всю ширину окна под план. Страницы без ЭУИ и освещения выбираются галочками и удаляются одной командой.
- Калибровка масштаба каждого листа по двум точкам. LED-линии и треки строятся из любого числа сегментов, их длина рассчитывается автоматически; каждый узел готовой линии можно перемещать.
- Каталог из БД: розетки, в том числе «Розетка с USB (2 в 1)» рядом с остальными розетками; одинарные/двойные/тройные, проходные и перекрёстные выключатели, терморегуляторы, светильники, треки, LED, датчики и карнизы. Типы ЭУИ имеют разные цвета точек по умолчанию; цвет отдельного обозначения можно изменить в свойствах объекта.
- Номенклатуры сгруппированы по назначению: розетки, диммеры, выключатели, реле и другие устройства. Внутри групп действует порядок по числу клавиш или каналов; сортировка применяется в библиотеке, каталоге, замене номенклатуры и отчётах. Доступны 10 вариантов звонковых/самовозвратных выключателей без разделения на НО/НЗ: 1–3 клавиши, подсветка, символ звонка, IP44/IP55 и управление жалюзи. Старые контактные варианты автоматически объединяются с сохранением объектов, товаров, количества и рамок.
- Наложение страниц настраивается отдельно для каждого слоя: слой можно перетаскивать мышью за любую точку рабочей поверхности (в том числе с выводом курсора за границу листа), точно сдвигать кнопками-стрелками, менять его прозрачность и масштаб от 10% до 500%, а результат применять кнопкой «ОК» или отменять без сохранения.
- Windows-приложение запускает собственный локальный сервер на отдельном порту и показывает номер версии внизу окна, поэтому после обновления не может случайно открыть интерфейс оставшейся в памяти старой версии.
- В номенклатуре есть отдельный слой «Умные устройства» с Zigbee-диммерами на 1–3 канала, реле на 1–3 канала, лампочками, контроллерами ленты, электрокарнизами, терморегуляторами, розетками, выключателями и датчиками.
- Встроенная панель каталога: производители, поставщики, товары, артикулы, цены и архивирование позиций; товар можно привязать к объекту на плане.
- Импорт и обновление прайс-листа из CSV с предварительной проверкой всех строк.
- Боковые панели и редактор КП используют узкие полосы иконок. Наведите мышь, чтобы увидеть подписи; щелчок открывает только выбранный инструмент, повторный щелчок на боковой панели сворачивает его. Свойства выбранного объекта открываются автоматически. В КП реквизиты и общая скидка находятся в инструменте «Реквизиты и условия», таблица — в «Позициях».
- В «Свойствах» доступны своё название, координаты точек и узлов в миллиметрах (до калибровки — в процентах), ручной метраж и свои текстовые/числовые/логические характеристики. «Оформление» меняет символ/надпись, форму, цвет, размер, поворот, подпись, толщину и штриховку линий для любой номенклатуры. Групповое оформление отменяется одним Ctrl+Z. Настройки сохраняются в PDF-плане и резервной копии.
- Номенклатуру можно копировать и задавать оформление для новых объектов; названия проектов и слоёв редактируются в интерфейсе. В КП доступны свои реквизиты строк, ручное количество поверх расчёта, копирование строк и добавление товаров из базы. Помеченные ручные правки сохраняются при обновлении из плана; количество по плану отображается отдельно. Если позиции с ручным количеством разделились или объединились, обновление просит снять ручное переопределение; разные ручные цены не объединяются без явного исправления.
- Поиск в выпадающих списках по любому фрагменту названия: щёлкните список или начните печатать, совпадения подсвечиваются; стрелки и Enter выбирают, Esc закрывает поиск. Каталог ищет также по артикулу, производителю и категории. Добавлена категория «Профиль» с метражом.
- Редактор КП прокручивается по вертикали, таблица — по обеим осям, заголовки колонок закреплены. Импорт PDF распознаёт разрядку и переносы заголовков, разный порядок колонок, продолжение таблиц, артикулы, цены, количество и процентные скидки. Перед переносом показывает страницу и сверку суммы каждой строки; спорные значения можно исправить, лишние строки удалить. Для сканов без текстового слоя требуется предварительное OCR.
- Резервная копия отдельного проекта в ZIP и восстановление проекта вместе с PDF, масштабом, слоями, объектами и связанными позициями каталога.
- Блок питания LED-ленты обозначается красным прямоугольником на плане и в его PDF. При размещении сначала укажите место блока: появится красный прямоугольник. Затем щёлкните на плане по одной или нескольким LED-лентам и нажмите «Готово» или Enter. Выбранные ленты подсвечиваются синим; повторный щелчок снимает выбор, Ctrl+Z/Ctrl+Y отменяют и возвращают выбор, Esc отменяет привязку. Можно выбирать ленты на разных листах; поддержаны и старые ленты с ручным метражом. ПКМ по блоку → «Привязать LED-ленты» изменяет связи. Первым пунктом ПКМ по блоку и по ленте идёт «Укажите мощность W»: задаётся общая мощность в ваттах, пустое поле убирает её. Связи и мощность доступны в свойствах, PDF/Excel и ZIP-копии; старые одиночные привязки обновляются автоматически. Несколько блоков могут питать одну ленту; перед удалением ленты связанные блоки нужно переназначить или удалить.
- Параметры LED, треков, карнизов; группировка по помещениям, категориям, типам и параметрам. Метраж не смешивается с количеством оборудования.
- Рекомендации IP для влажных помещений (это подсказки комплектации, не проверка соответствия электротехническим нормам).
- Экспорт Excel с отдельными листами по категориям и помещениям, сводный PDF, браузерная печать и PDF текущего плана с размеченными слоями.

## Быстрый запуск в подготовленной облачной среде

Используйте существующий checkout, отдельный worktree не нужен.

```bash
bash /workspace/smart-home-calc-dev/start-db.sh
source /workspace/smart-home-calc-dev/env.sh
cd /workspace/Smart-Calc-for-electricity-projects/backend
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

В другом терминале:

```bash
cd /workspace/Smart-Calc-for-electricity-projects/frontend
npm ci
npm run dev -- --port 5173
```

Frontend обращается к `/api` через proxy Vite на backend порта 8000. API-документация доступна на пути `/docs` backend; проверка состояния — `/api/health`. Процессы запускаются заново после восстановления среды. PostgreSQL — отдельный кластер локальной разработки с Unix-сокетом, не публичный сервер.

## Запуск на своём компьютере через Docker

Это основной способ локального тестирования на Windows, macOS и Linux. Установите Docker Desktop, скачайте репозиторий через **Code → Download ZIP**, распакуйте его и откройте терминал в папке проекта.

```bash
docker compose up --build
```

Когда контейнеры перейдут в состояние `healthy`, откройте <http://localhost:5173>. Документация API доступна на <http://localhost:8000/docs>.

Остановка без удаления данных:

```bash
docker compose down
```

Повторный запуск использует те же проекты, PDF и базу данных:

```bash
docker compose up
```

Данные находятся в именованных Docker volumes `smart-home-calc_postgres_data` и `smart-home-calc_project_files`. Контейнер `backup` автоматически сохраняет оба хранилища в локальную папку `backups`. Команда `docker compose down -v` удалит Docker volumes, поэтому не используйте флаг `-v` для обычной остановки и сначала убедитесь, что полная резервная копия существует.

Локальные значения предназначены только для тестового компьютера. Чтобы изменить пароль, скопируйте `.env.docker.example` в `.env`, измените `POSTGRES_PASSWORD` и пароль внутри `DATABASE_URL` до первого запуска. Не добавляйте `.env` в Git.

## Ручной запуск вне облачной среды

Нужны Node.js 22.12+ (или 24), Python 3.12+, PostgreSQL 17 и шрифт с кириллицей. Путь к шрифту задаётся через `PDF_FONT_PATH`; приложение также ищет DejaVu Sans в Linux и Arial в Windows. Docker-образ уже содержит нужный шрифт.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
```

## Структура

- `backend/app/models.py`: модель данных; `db.py`: подключения и сессии.

## Работа с масштабом и линиями

На нужном рабочем листе нажмите **Масштаб, мм**, отметьте две точки известного размера и введите расстояние в миллиметрах (например, 5000 для 5 метров). После этого выберите `LED-линия` или `Трек`, включите размещение, последовательно отметьте все узлы и нажмите **Завершить линию**. Выберите готовую линию, чтобы перемещать её белые узлы. Длины лент и треков в спецификации по-прежнему выводятся в метрах. Масштабы старых проектов, откалиброванных в метрах, сохраняют реальные размеры: прежние 5 м соответствуют новому вводу 5000 мм. При запуске приложение проверяет линии во всех проектах и пересчитывает устаревшие длины по их геометрии и сохранённому масштабу; повторный запуск не меняет уже правильные длины. Рассчитанную длину нельзя изменить вручную: она пересчитывается сервером из геометрии и масштаба листа, в том числе сразу после повторной калибровки всех линий этого листа.

Кнопка **План PDF** экспортирует текущую исходную страницу с объектами тех слоёв, у которых включён флаг ведомости/экспорта.

Для разметки помещения нажмите **Область помещения** и последовательно поставьте любое число вершин. Контур тянется за курсором; `Shift` фиксирует следующий отрезок по горизонтали или вертикали, `Backspace`/`Ctrl+Z` удаляет последнюю вершину, `Enter` замыкает область. Новую область также можно замкнуть щелчком по первой точке. Размер управляющих точек соответствует общему масштабу обозначений. Самопересекающиеся контуры не сохраняются. После ввода названия контур скрывается. Щёлкните правой кнопкой внутри области, чтобы открыть меню: контур можно снова показать и передвинуть его вершины, переименовать помещение или удалить его. При изменении контура привязка всех элементов на листе пересчитывается автоматически.

Во время создания или редактирования области щёлкните правой кнопкой на плане: через контекстное меню можно добавить вершину в ближайший сегмент или удалить ближайшую вершину. Минимум для замкнутой области — три точки.

Вкладка **Спецификация** показывает ведомость, разбитую на помещения. Внутри каждого помещения сначала показаны все электроустановки, затем рамки, после них — остальные категории. В конце находится полный итог с разбивкой ЭУИ и рамок, общим количеством электроустановок, рамок и постов. В этой же вкладке доступны сохранение Excel/PDF и печать.

Кнопка **Каталог и цены** открывает вкладки **Номенклатура** и **Товары и цены**. Во вкладке номенклатуры доступны поиск, добавление, редактирование названия, категории, единицы, цвета, рекомендуемого IP и параметров по умолчанию; удаление из библиотеки и восстановление через «Показывать удалённые». Изменённые встроенные позиции не пересоздаются после перезапуска. Удаление из библиотеки сохраняет уже размещённые объекты, рамки, товары и отчёты; новая установка скрытой позиции запрещена. Категория и единица используемой позиции защищены от изменения — для них создайте отдельную позицию.

Во вкладке товаров можно добавить производителя и поставщика, создать или отредактировать товар, изменить цену и удалить товар из выбора. Существующие привязки и стоимость сохраняются; восстановить товар можно флагом «Доступен для выбора». После создания товар выбирается в свойствах объекта; стоимость появляется в ведомости и экспорте.

Прайс-лист импортируется в этой же панели. Скачайте **Шаблон CSV** и заполните столбцы `name`, `sku`, `type`, `manufacturer`, `supplier`, `price`, `currency`, `active`. Название типа должно точно совпадать с типом из библиотеки. Разделители `;`, `,` и табуляция поддерживаются автоматически, файл должен быть в UTF-8 и размером до 2 МБ. Если артикул и производитель уже существуют, цена и остальные поля товара обновляются. При ошибке ни одна строка файла не сохраняется.

## Резервное копирование проекта

Откройте проект и нажмите **Резервная копия** на панели плана. Будет скачан ZIP с версионированным `manifest.json` и исходными PDF. В архив входят названия и масштаб листов, помещения, состояния слоёв, геометрия и параметры объектов, а также используемые типы и товары.

Для восстановления нажмите **Восстановить ZIP** в верхней панели. Приложение создаст новый проект, не изменяя исходный. Архив проверяется до записи: максимальный размер загрузки — 100 МБ, распакованных данных — 250 МБ, одного PDF — 20 МБ. Повреждённые, зашифрованные и архивы с небезопасными путями отклоняются целиком.

## Автоматическая копия Docker-установки

При запуске `docker compose up` сервис `backup` сразу создаёт полную копию, затем повторяет её раз в 24 часа. Каждая копия находится в `backups/ГГГГММДДTЧЧММССZ` и содержит:

- `database.dump` — PostgreSQL в формате `pg_dump`;
- `project-files.tar.gz` — все исходные PDF и изображения листов;
- `SHA256SUMS` — контрольные суммы;
- `backup.meta` — версия формата и время создания в UTC.

По умолчанию копии старше 14 дней удаляются. Интервал и срок хранения задаются в `.env`:

```env
BACKUP_INTERVAL_HOURS=24
BACKUP_RETENTION_DAYS=14
```

Значение срока хранения `0` отключает автоматическое удаление. Чтобы создать копию немедленно, перезапустите только сервис резервирования:

```bash
docker compose restart backup
```

Для восстановления сначала найдите имя нужной папки в `backups`. Операция полностью заменяет текущую базу и файловое хранилище и требует ввода слова `RESTORE`.

macOS, Linux или Git Bash/WSL:

```bash
./scripts/restore-backup.sh 20261011T120000Z
```

Windows PowerShell:

```powershell
.\scripts\restore-backup.ps1 -BackupName 20261011T120000Z
```

Перед заменой сценарий проверяет `SHA256SUMS`. После восстановления контейнеры приложения запускаются снова. Папку `backups` следует дополнительно копировать на внешний диск: хранение копии рядом с приложением не защищает от поломки или потери компьютера.

Это однопользовательское офлайн-приложение для доверенного компьютера. Регистрация, авторизация и разграничение доступа намеренно не входят в архитектуру проекта.
