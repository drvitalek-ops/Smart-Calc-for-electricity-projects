# Перенос Smart Home Calc на другой компьютер

Для автономной Windows-версии (файл `SmartHomeCalc-Windows-x64.exe`). Интернет нужен только для скачивания приложения или установки WebView2, если его нет в Windows.

## Копия ZIP из приложения (v1.0.43)

Откройте **Настройки → Скачать полную копию ZIP**. Сначала сохраните КП и
завершите построение на плане. Архив включает все проекты, самостоятельные
КП, каталог с фотографиями, категории и PDF-планы; во время его создания
приложение может оставаться открытым.

На другом ПК распакуйте ZIP в отдельную папку, закройте калькулятор и
запустите `Restore-data.cmd`. Подтвердите восстановление словом
`ВОССТАНОВИТЬ`. Скрипт проверит контрольные суммы и сохранит прежнюю папку
данных рядом как `data-before-restore-…`. Затем запустите EXE.

Это перенос всей базы, а не объединение с базой другого компьютера.
Персональные настройки вида рабочей области хранятся отдельно на этом ПК.

## Полный перенос: все проекты и весь каталог

Рабочие данные находятся в папке `%LOCALAPPDATA%\SmartHomeCalc\data`:

| Что | Где хранится |
| --- | --- |
| Все проекты, помещения, слои, объекты, рамки, масштабы и настройки наложения листов | `smart-home-calc.db` |
| Полный каталог, включая неиспользованные товары, производителей, поставщиков, контакты и цены | `smart-home-calc.db` |
| Исходные PDF и изображения листов | `storage` |

1. На старом компьютере дождитесь автосохранения последних правок. Нажмите **Настройки → Открыть папку данных** — откроется Проводник. Затем **полностью закройте Smart Home Calc**. Не копируйте открытую базу.
2. В открытом Проводнике нажмите `Alt + ↑`, чтобы перейти к родительской папке `SmartHomeCalc`. В старых версиях без кнопки настроек используйте `Win + R` и путь `%LOCALAPPDATA%\SmartHomeCalc`.
3. Скопируйте папку **`data` целиком** на флешку, внешний диск или в архив ZIP. База без `storage` не содержит PDF-планы; одних PDF также недостаточно.
4. На новом компьютере скачайте актуальную версию приложения, запустите один раз, нажмите **Настройки → Открыть папку данных** и закройте приложение. Папка данных будет создана автоматически. Docker, Python и PostgreSQL не нужны.
5. В Проводнике нажмите `Alt + ↑`, чтобы открыть папку `SmartHomeCalc`. Если здесь уже есть нужные проекты, сначала сохраните существующую папку `data` отдельно. **Замена папки переносит базу целиком, а не объединяет две базы.**
6. Замените созданную папку `data` копией со старого компьютера. Должны получиться `...\SmartHomeCalc\data\smart-home-calc.db` и `...\SmartHomeCalc\data\storage\…`, без дополнительного вложения `data\data`.
7. Запустите новое приложение. Начиная с v1.0.25 пути к файлам в `storage` автоматически привязываются к папке нового пользователя Windows.
8. Проверьте несколько проектов: открываются ли PDF, видны ли объекты и рамки, заполнен ли каталог и формируются ли спецификации. Сохраняйте исходную копию до проверки.

EXE и папка загрузок не содержат рабочую базу. PDF/Excel, ранее выгруженные в «Загрузки» или «Документы», нужно скопировать отдельно, если они нужны: это самостоятельные файлы. Настройки внешнего вида интерфейса, сохранённые в профиле WebView2 (например размер обозначений), могут потребовать повторной настройки; состав проектов от этого не меняется.

## Перенос одного проекта или объединение с данными нового компьютера

На старом компьютере откройте проект и нажмите **Резервная копия** на панели плана. На новом нажмите **Восстановить ZIP** и выберите архив. Создастся новый проект, существующие проекты останутся на месте.

В ZIP входят исходные PDF, страницы и их масштабы, параметры наложения, помещения, слои, объекты и рамки, а также используемые проектом типы и товары. **Неиспользуемые позиции общего каталога в ZIP проекта не входят.** Для переноса полного каталога используйте полную копию папки `data`.

Этот способ ограничен размером архива: PDF проекта суммарно до 90 МБ при создании копии; при восстановлении — ZIP до 100 МБ, распакованные данные до 250 МБ, один PDF до 20 МБ. Для больших проектов используйте полный перенос папки данных.

## Если приложение запущено через Docker

Папка `%LOCALAPPDATA%\SmartHomeCalc\data` относится только к автономной Windows-версии. Для Docker переносите полную резервную копию базы PostgreSQL и файлового хранилища из `backups` и восстанавливайте её штатными сценариями. Порядок описан в README в разделе «Автоматическая копия Docker-установки». SQLite и PostgreSQL нельзя переносить простой заменой файлов друг на друга.
