# v1.0.48 — количества КП с учётом переноса проекта

Включает изменения v1.0.46 и v1.0.47:

- Компактные цветные значки на плане, разные обозначения типов светильников,
  автоматическое упрощение при уменьшении масштаба.
- Группы внутри слоёв с галочками и командами «Показать все» / «Скрыть все».
- Автоматическое количество связанных строк КП при открытии, сохранении,
  предпросмотре и экспорте в PDF. Ручные цены, скидки, комментарии и порядок
  сохраняются. Галочка «Вручную» задаёт приоритет ручного количества.

Уточнено сохранение связи строки с расчётной группой при назначении товара
и восстановлении ZIP-проекта с новыми идентификаторами каталога. Если после
добавления одинаковых объектов исходный объект удалён, количество строки
продолжает считаться по оставшимся объектам с сохранением её цены.

Проверены отмена удаления, метраж лент, количество рамок, перенос ZIP,
сохранение ручных групп и удалённых из КП строк. Новые типы позиций добавляются
кнопкой «Обновить из расчёта»; самостоятельные и ручные строки не меняются.

Перед обновлением можно создать полную ZIP-копию в настройках.
Предыдущие выпуски доступны в Releases для отката.
