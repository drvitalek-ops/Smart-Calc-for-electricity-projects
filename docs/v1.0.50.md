# v1.0.50 — «Сделать SKU»: таблица Word без цен

В редакторе КП появилась кнопка «Сделать SKU». Она доступна в левой панели
инструментов и в закреплённой панели возле списка позиций.

Кнопка скачивает редактируемый файл Word (.docx) с таблицей:
«№», «Наименование», «Количество», «Ед.». Дробные количества выводятся
с запятой; штуки и метры различаются отдельным столбцом. Документ имеет
формат A4, перенос длинных наименований и повторение заголовка таблицы.
Microsoft Word не требуется для формирования файла.

Выгружаются все строки КП в текущем порядке, включая несохранённые
наименования и количества. Поиск, фильтр помещения и страница редактора
не ограничивают состав выгрузки. Для связанных строк используется актуальное
количество с плана, а галочка «Вручную» сохраняет заданный пользователем объём.

Цены, скидки, суммы, фотографии, описания, комментарии и условия КП
не включаются в документ. SKU можно сформировать до заполнения цен.
Нужны заполненные наименования и корректные положительные количества.

Выгрузка работает для КП проекта и самостоятельного КП. Она не сохраняет
и не заменяет КП: текущие правки остаются в редакторе, кнопка сохранения
продолжает работать отдельно.

Формат хранилища не менялся. Перед обновлением доступна полная ZIP-копия
в настройках; предыдущий выпуск v1.0.49 остаётся доступен для отката.
