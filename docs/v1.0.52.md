# v1.0.52 — распределение КП по помещениям плана

Новые КП проекта открываются общим списком: одинаковые позиции из разных
помещений объединены с суммарным количеством. Товар, артикул, бренд, цену и
скидку достаточно назначить один раз. Привязка товара применяется ко всем
связанным объектам на плане.

В разделе «Позиции» нажмите «Распределить по помещениям». Светильники,
электроустановки и рамки разделятся по помещениям, назначенным объектам
на плане. Их товары, цены, скидки, комментарии и фотографии сохранятся.
Объекты без помещения попадут в «Без помещения». Ленты и прочие категории
останутся суммарными строками в «Общие позиции».

Разбивка отображается в редакторе, предпросмотре и PDF. Word-SKU
выгружает позиции и количества из текущего списка.
«Объединить помещения» возвращает общий список. Строки с разными ценами,
скидками или другими ручными условиями остаются отдельными. При изменении
плана связанные количества обновляются как прежде; для нового распределения
по комнатам нажмите кнопку ещё раз.

Ручные строки не распределяются без связи с планом. В самостоятельном КП
кнопка недоступна; сначала прикрепите КП к проекту и добавьте позиции
через «Обновить из расчёта». Если вручную заданное количество приходится
делить между комнатами, приложение попросит снять «Вручную», сохранив КП.
Для рамок с разными условиями объединение потребует их согласовать.

Ранее сохранённые КП продолжают использовать свою разбивку до нажатия
кнопки. Структура базы не менялась; полная ZIP-копия доступна в настройках.
Для отката сохранён выпуск v1.0.51. При возврате к нему используйте
копию данных до обновления: новый режим объединения рамок требует v1.0.52.
