# Smart Home Calc v1.0.55

Полное визуальное обновление рабочих экранов приложения. Новый вид включён
непосредственно в Windows EXE: отдельный файл дизайн-системы нужен только
для просмотра правил и компонентов.

## Что изменилось

- Тёмная верхняя панель с иконками разделов и белая строка проекта. На небольшом
  экране второстепенные действия становятся компактными, названия доступны
  через подсказки и программы чтения экрана.
- Новое оформление инструментов плана, слоёв, свойств и страниц: заголовки
  с пояснениями, контурные иконки, белые карточки и спокойный фон чертежа.
- Каталог с постоянной навигацией «Номенклатура», «Товары и цены», «Категории».
  Список слева, редактор справа; обе части прокручиваются независимо.
  Номенклатура показывает реальные обозначения объектов, товары — фотографии.
- Редактор КП с новым заголовком, компактными итогами и постоянной панелью
  действий. Сохранены артикул, бренд, ручное количество, перетаскивание,
  комментарии, помещения, поиск и импорт.
- Список КП с карточками, количеством документов и фильтрами «Все»,
  «С проектом», «Без проекта».
- Настройки с боковой навигацией и карточками данных, рабочей области,
  резервной копии, отката и переноса. Переход прокручивает нужный раздел.
- Обновлены стартовый экран, спецификация, формы, меню и состояния.
  Шрифты и значки работают без интернета.
- Дизайн-система 1.1: 91 токен, 19 проверяемых пар контраста, общие компоненты
  заголовков и карточек, интерактивный HTML и исходники в ZIP.

## Проверка

180 серверных тестов и 25 браузерных сценариев. Проверены минимальное окно
1024×700, каталог, редактирование и импорт КП, фотографии, поиск, рамки,
полигоны, блоки питания, отмена, экспорт Word/Excel/PDF и откат версии.
Проверка Windows-сборки дополнительно загружает реальные JS/CSS из
упакованного EXE и подтверждает наличие обновлённого интерфейса.

## PDF и данные

Утверждённый шаблон PDF КП сохранён: логотип, положение суммы, шрифт таблицы,
комментарии и разбивка по помещениям. Обновление экрана не меняет
рендерер документа, количество объектов и формат хранения данных.

## Установка и возврат к предыдущей версии

Скачайте **SmartHomeCalc-Windows-x64.exe** из этого релиза. Закройте старое
приложение и запустите новый файл. Внизу окна должна отображаться **1.0.55**.
Дополнительная установка Docker или PostgreSQL не требуется.

Перед заменой EXE сохраните полную копию ZIP через «Настройки» → «Резервная
копия» и оставьте предыдущий EXE. Для возврата доступен
[релиз v1.0.54](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.54).
Совместимость проверяется на отдельной базе: v1.0.54 → v1.0.55 → v1.0.54.

HTML и ZIP дизайн-системы — дополнительные материалы. Для работы
с планами и КП запускайте EXE.
