# Smart Home Calc v1.0.57

Единая база товаров и производителей для каталога, калькулятора плана и редактора КП.

## Товары и производители

- В редакторе товара можно ввести нового производителя и добавить его прямо из поля. При сохранении товара введённый производитель также создаётся автоматически.
- Названия производителей сравниваются без учёта регистра, лишних пробелов и различия «е/ё». Одновременное создание из нескольких окон не создаёт дубликаты.
- При совпадении артикула или похожем названии приложение предлагает отредактировать существующую карточку, создать отдельную позицию или отменить действие. Выбранная карточка загружается для проверки перед сохранением.
- В свойствах позиции КП доступны редактирование привязанного товара в общей базе и удаление товара.
- Производителей и товары можно удалить из рабочего списка. Удаление переносит их в архив, сохраняя связи с проектами и КП. Удаление производителя архивирует его товары. Включите «Показывать удалённые товары и производителей», чтобы восстановить производителя, затем нужные товары.

## Синхронизация

После сохранения карточки изменения доступны во всех инструментах и других открытых окнах приложения. Уже открытые формы получают изменения незаполненных вручную полей, сохраняя собственные правки пользователя.

Название, бренд, артикул и изображение привязанного товара обновляются в КП, если поле не было изменено вручную. **Цены, валюта, количество и скидки существующих КП сохраняются.** Актуальная цена базы применяется при новом выборе товара. Редактирование карточки уже привязанного товара из КП также сохраняет согласованную цену этого КП.

CSV-импорт использует ту же базу производителей и товаров; обновление метаданных не меняет финансовые условия существующих КП. Неоднозначные совпадения требуют исправления дублей в каталоге.

## Проверка и обновление

Проверены серверные сценарии, работа в двух окнах, предупреждение о дублях, редактирование открытой карточки, архивирование и сохранение связей. Полный набор проверок включает расчёты, перетаскивание объектов, Ctrl+Z, оформление PDF и совместимость данных с предыдущими версиями.

Скачайте `SmartHomeCalc-Windows-x64.exe`. HTML и ZIP дизайн-системы для работы приложения не требуются. Обновление добавляет признак архива производителя в локальную базу автоматически.

Перед заменой EXE закройте приложение и скопируйте всю папку данных через настройки. Для отката сохранён [релиз v1.0.56](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.56): закройте новую версию, запустите предыдущий EXE; резервная копия возвращает состояние данных на момент её создания.
