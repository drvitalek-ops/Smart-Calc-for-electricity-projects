# Smart Home Calc v1.0.59

Создание товара с фотографией прямо на плане и назначение одной карточки всем выбранным объектам.

## Работа на плане

1. Выделите объекты и откройте «Свойства». В блоке «Товар для выбранных» выберите товар и нажмите «Применить товар ко всем». Для одного объекта выбор сохраняется сразу.
2. Если товара нет, введите название в поиск и выберите «Добавить товар … в базу». Доступна также отдельная кнопка добавления с плана.
3. Заполните название, номенклатуру, производителя, артикул, цену и валюту. Добавьте фото из файла, через Ctrl+V или перетаскиванием. Форма дожидается подготовки изображения перед сохранением.
4. «Создать и назначить выбранным» сохраняет одну карточку в общей базе и назначает её выбранным объектам. Эта же карточка с фотографией доступна в каталоге и редакторе КП, без повторного ввода и загрузки изображения.

Для плана и КП используется одна форма карточки товара. Производителя можно добавить прямо из неё. При похожей карточке приложение предлагает проверить существующий товар, отредактировать его или использовать без создания дубликата.

Один товар назначается объектам одной номенклатуры и совместимых единиц. При смешанном выделении можно выбрать нужную группу прямо в блоке товара. Типы объектов, размеры, количества и расстановка сохраняются. Заблокированный слой или ошибка проверки отменяют всю операцию.

Ctrl+Z отменяет назначение всей группе одним действием; Ctrl+Shift+Z возвращает его. Созданная карточка остаётся в общей базе для дальнейшего использования. Привязку товара можно снять у всех выбранных объектов.

## Связь с КП

Фотография, название, артикул и производитель из новой привязки на плане подтягиваются в связанные позиции КП. Ручные правки этих полей сохраняются. Если товар назначен только части объектов общей строки, КП разделяет их по товарам с сохранением условий строк.

**Цены, валюта и скидки ранее сохранённых КП остаются прежними.** Новые КП берут актуальную цену из базы. Сохраняются также цены, подставленные в старых КП из одинаковых уже оценённых позиций.

Ручное количество не делится автоматически между разными товарами. Если разделение строки изменяет итог вследствие округления, приложение объясняет причину и предлагает назначить товар всей строке либо изменить разбивку КП вручную. Карточка и привязки при неудачной операции не создаются частично.

Проверки включают создание и повторное использование карточки, три способа добавления фото, обмен между открытыми инструментами, защиту черновиков и финансовых условий, точность округления, отмену/повтор и совместимость PDF.

Для обновления нужен `SmartHomeCalc-Windows-x64.exe`. Закройте приложение и создайте копию папки данных через настройки перед заменой EXE. Для отката сохранён [релиз v1.0.58](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.58).
