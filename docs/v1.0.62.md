# Smart Home Calc v1.0.62

Исправлен пропуск новых объектов плана в уже созданном КП, в том числе блоков питания новой номенклатуры.

Раньше автоматическое обновление меняло количества только для знакомых строк. Новая номенклатура или блок питания с другой мощностью/привязкой к лентам образовывали новую группу расчёта, которая автоматически не добавлялась. Теперь новые объекты добавляются при открытии, сохранении и формировании КП. Уже созданные проекты исправляются при открытии КП, включая ранее пустые КП.

Ранее сохранённые строки сохраняют цены, валюту, скидки, комментарии, фотографии, ручные поля и ручное количество. Новые строки берут данные привязанного товара из общей базы; объекты без товара тоже учитываются по количеству. Повторное чтение не создаёт дубли. Самостоятельные КП и прикреплённые ручные КП остаются независимыми от плана до явного обновления из расчёта.

Намеренно удалённые из КП объекты запоминаются и не возвращаются при обычном обновлении количества или распределении по помещениям. «Обновить из расчёта» восстанавливает их явно. Сохранение из старого окна добавляет ещё не показанные новые объекты, сохраняя введённые условия. Исключения корректно переносятся в ZIP проекта с новыми идентификаторами объектов. Предпросмотр PDF и SKU из несохранённого черновика учитывают эти же исключения без записи документа. Перед формированием PDF проверяются актуальные позиции плана, включая ещё не оценённые новые блоки. Состояние синхронизации хранится в JSON КП; схема базы не меняется.

При явном обновлении из расчёта сохраняются цены ранее сохранённых строк, включая цены выбранного товара после изменения прайс-листа. Объединение строк с разными согласованными ценами или валютами требует сначала согласовать условия и не выполняется молча. Расчёт и ручное удаление агрегированных строк рамок сохраняют прежнюю логику.

В Windows/SQLite новые объекты получают последовательные номера без повторного использования удалённых номеров, в том числе после перезапуска. Новый блок питания не наследует исключение ранее удалённого из КП блока. Существующая база обновляется при запуске без перестройки таблиц.

Номенклатура задаёт название, единицу и графическое обозначение объекта. После её создания доступна кнопка «Создать товар»: она открывает карточку с нужными названием и типом. Заполните производителя, артикул, цену и фото и сохраните — карточка появится в «Товары и цены» и будет доступна для выбора на плане и в КП. Для существующей номенклатуры такая кнопка доступна при её редактировании. Привязка выбранной карточки определяет, какие фото, артикул и цена используются у конкретной позиции.

Если у слоя отключён флажок включения в ведомость, его объекты по-прежнему исключаются из расчёта и КП. Теперь проверка плана показывает причину и указывает, какой флажок включить. Обычное скрытие слоя не исключает объекты из расчёта.

Проверены новая номенклатура блоков питания, создание карточки с фото, связанные и ещё не оценённые блоки на плане, сохранность старых цен/скидок, ручные исключения, новые группы, перенос проекта, распределение по помещениям и диагностика слоёв.

Для обновления нужен `SmartHomeCalc-Windows-x64.exe`; перед запуском закройте предыдущую версию. [Релиз v1.0.61](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.61) сохранён для отката.
