# Smart Home Calc v1.0.63

В КП кнопка «Распределить по помещениям» теперь использует помещения всех позиций спецификации. Снято ограничение на категории: распределяются электроустановки, рамки, светильники, LED-ленты, блоки питания, профили, датчики, электрокарнизы, умные устройства и пользовательская номенклатура.

У каждой позиции сохраняется помещение, назначенное на плане. Блок питания относится к помещению его размещения, как в спецификации; связь с лентой в другом помещении не переносит сам блок. Объекты без назначенного помещения попадают в «Без помещения». Слои с отключённым включением в ведомость по-прежнему исключаются из расчёта и КП.

Обычное КП по умолчанию остаётся общим. Разбивка включается кнопкой «Распределить по помещениям» и используется в редакторе и PDF. «Объединить помещения» возвращает общий список. Для ранее созданного КП с частью строк в «Общих позициях» нажмите «Распределить по помещениям» повторно.

Сохраняются согласованные цены, валюты, скидки, комментарии, фотографии, артикулы, ручные поля и отдельные ручные строки. Количества берутся с плана; длины лент и профилей остаются в метрах. Ручное количество, которое нельзя однозначно разбить между помещениями, по-прежнему требует снять флажок «Вручную». Намеренно удалённые из КП позиции не восстанавливаются этой кнопкой.

Проверены распределение всех категорий без светильников и электроустановок, совпадение с общей спецификацией, позиции без помещения, блоки с лентами в другом помещении, оба PDF, повторная разбивка старого КП, объединение, сохранность цен/скидок и интерфейс кнопки.

Схема базы, расстановка, расчёт рамок и дизайн PDF не меняются. Для обновления закройте предыдущую версию и запустите `SmartHomeCalc-Windows-x64.exe`. [Релиз v1.0.62](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.62) сохранён для отката.
