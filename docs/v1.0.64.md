# Smart Home Calc v1.0.64

В общем КП одинаковые товары автоматически объединяются: например, шесть одинаковых блоков питания отображаются одной строкой с количеством 6 шт. Товар определяется выбранной карточкой и согласованными данными строки. Для позиций без карточки учитываются номенклатура, название и характеристики; разные мощности или исполнения не смешиваются. Служебные связи одинаковых блоков с разными лентами больше не дробят КП.

«Распределить по помещениям» создаёт последовательные группы комнат: помещение и все его позиции, затем следующее помещение. Одинаковый товар объединяется внутри комнаты. «Объединить помещения» снова собирает его в общую строку. Логика действует для всех категорий, включая ленты, профили, блоки питания, датчики, умные устройства, электрокарнизы, освещение, электроустановки и пользовательскую номенклатуру. Позиции без помещения остаются в соответствующей группе.

Строки ранее созданных КП объединяются при открытии; новые — при сохранении, выборе товара и обновлении из расчёта. Одинаковые ручные строки также суммируются при сохранении. Во время ввода строки остаются доступными для редактирования. Выбор товара после объединения черновых строк корректно привязывает его к оставшейся строке.

Объединяются только строки с одинаковыми ценами, валютой, скидкой и ручными данными. Разные комментарии, ручные описания, ручные группы и коммерческие условия сохраняются отдельно. Объединение не меняет суммы клиента и партнёра из-за округления и соблюдает максимальное количество строки. Добавленные вручную количества и связанные с планом строки остаются самостоятельными источниками количества. Ручное количество нельзя автоматически распределять между несколькими комнатами: сохраняется существующая проверка флажка «Вручную».

Ссылки на все исходные объекты сохраняются: количество обновляется после изменений плана, удаления и Ctrl+Z. Длины лент и профилей суммируются в метрах. Намеренные исключения из КП сохраняются. Характеристики, общие для объединённой модели, остаются в КП; индивидуальные связи с лентами и монтажные данные доступны в подробной спецификации и на плане. Сама спецификация и расстановка не меняются.

Проверены шесть одинаковых блоков с разными лентами, объединение и разбивка по двум помещениям, все категории и метры, старые КП, ручные строки, точные суммы, ручное количество, PDF, SKU и удаление/отмена на плане.

Схема базы и дизайн PDF не меняются. Для обновления закройте старую версию и запустите `SmartHomeCalc-Windows-x64.exe`. [Релиз v1.0.63](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.63) сохранён для отката.
