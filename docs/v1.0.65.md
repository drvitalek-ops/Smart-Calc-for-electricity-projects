# Smart Home Calc v1.0.65

Связанные позиции КП обновляют существующие объекты плана при сохранении. Изменение количества распределяется между исходными объектами пропорционально их количеству с точной суммой; новые точки не создаются и существующие не удаляются. Для штук допускается целое количество, для линий — метры с точностью до миллиметра. При изменении длины узлы остаются на своих местах, задаётся ручная длина с сохранением измеренной геометрии.

Название, IP и комментарий передаются объектам. Артикул, бренд, цена, валюта и описание сохраняются как данные позиций конкретного проекта; общий прайс-лист и другие КП не переоцениваются. На плане карточка выбранного товара и спецификация показывают данные позиции. Ручные строки КП без привязки остаются только в КП. Изменение заблокированных объектов отклоняется целиком. Сохранение старого окна без редактирования количества не возвращает план к устаревшему количеству. Операция отменяется одним Ctrl+Z на плане.

В каталоге, КП и форме создания товара с плана номенклатура необязательна. Товар без неё можно сохранить с фотографией, артикулом, производителем и ценой, затем использовать в КП и назначать объектам с совместимой единицей измерения. В каталоге единица выбирается отдельно. Расстановка, типы объектов и расчёт рамок сохраняются. Поддерживается перенос таких товаров вместе с проектом через ZIP без перестройки существующей базы.

Исправлена прокрутка каталога с длинным справочником производителей: список имеет собственную область прокрутки, а товары и флажок показа архива остаются доступными.

Добавлены в «Освещение»: шинопровод, трековый светильник, трековый линейный светильник, трековый спот, трековый подвес, блок питания трека, прямой, угловой, Т-образный и гибкий соединители, ввод питания, заглушка, подвес и крепление трека. Шинопровод размечается так же, как LED-линия: несколько узлов, завершение Enter, редактирование узлов, измерение по калибровке и Ctrl+Z. Трековый блок питания размещается отдельно и не требует привязки к LED-ленте.

Исправлено отображение выбранных цветов. Индивидуальный цвет виден в заливке обозначения с контрастным знаком и сохраняется в PDF плана. Палитра и HEX работают сразу; простое посещение HEX-поля больше не закрепляет автоматический цвет как индивидуальный. Кнопка «Цвет номенклатуры» возвращает наследование цвета. Цвет по умолчанию и оформление номенклатуры больше не конфликтуют в форме.

Проверены обратная синхронизация КП, распределение 6 → 8 по шести существующим точкам и отмена, защита заблокированных объектов и устаревших количеств, товары без номенклатуры и ZIP, шинопровод с калибровкой, палитра/HEX/сброс, PDF и прежние функции приложения.

Для обновления закройте старую версию и запустите `SmartHomeCalc-Windows-x64.exe`. [Релиз v1.0.64](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.64) сохранён для отката.
