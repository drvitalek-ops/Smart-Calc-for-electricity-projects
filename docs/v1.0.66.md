# Smart Home Calc v1.0.66

Исправлено отсутствие рамок в КП при распределении по помещениям. Ранее рамки, сформированные после первого создания КП, не добавлялись в него автоматически: синхронизация новых объектов учитывала точки и линии, а рамки обрабатывались отдельно и только при наличии прежней строки. Теперь рамки из спецификации автоматически попадают в связанное КП, в том числе в уже сохранённых проектах.

В общем КП одинаковые рамки суммируются, а при распределении показываются в своих помещениях. Согласованные товары, цены, скидки и комментарии сохраняются; новые рамки того же размера наследуют однозначные условия существующей позиции. Другой размер рамки добавляется отдельной строкой. При разных условиях система не подставляет произвольную цену.

Намеренно удалённые строки рамок остаются исключёнными при повторном открытии, переключении общего списка и помещений, переносе проекта через ZIP и выгрузке PDF/SKU. Кнопка «Обновить из расчёта» явно восстанавливает исключённые позиции. Дизайн КП, расстановка и расчёт постов на плане сохраняются.

Проверены создание рамок после сохранения КП, помещения, общее количество, цены и скидки, новые размеры, восстановление старых КП, удаление строк, PDF для клиента и партнёра, Word SKU и ZIP. Новые служебные сведения хранятся в данных КП без изменения схемы базы.

Для обновления закройте предыдущую версию и запустите `SmartHomeCalc-Windows-x64.exe`. [Релиз v1.0.65](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.65) сохранён для отката.
