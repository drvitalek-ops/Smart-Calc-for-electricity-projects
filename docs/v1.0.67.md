# Smart Home Calc v1.0.67

Часто редактируемые поля перенесены в рабочую область редактора КП:

- Общая скидка находится в заголовке столбца «Скидка, %», рядом со скидками отдельных строк. Закреплённый заголовок сохраняет доступ к ней при прокрутке таблицы.
- Имя и контакт клиента находятся в шапке рядом с номером КП и доступны при переключении инструментов редактора.
- Эти поля убраны из «Реквизитов и условий», чтобы не дублировать ввод.

Логика расчёта прежняя: пустая скидка строки использует общую; индивидуальная скидка, включая 0%, заменяет общую. PDF для клиента формируется без скидок, для партнёра — со скидками. Имя и контакт клиента передаются в PDF как раньше. Сохраняются Ctrl+Z, сохранение черновика, проверка чисел и переход к полю с ошибкой. Дизайн итогового PDF не меняется.

Проверены размещение полей на широком и узком экране, общая и индивидуальные скидки, точные итоги, отмена, сохранение и оба PDF. Существующие КП и база данных совместимы без переноса данных.

Перед обновлением закройте старое приложение, затем запустите `SmartHomeCalc-Windows-x64.exe`. [Релиз v1.0.66](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.66) сохранён для отката.
