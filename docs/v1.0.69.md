# Smart Home Calc v1.0.69

Исправлен выбор рамок на плане. Раньше срабатывала только узкая граница контура; в инструменте «Рамки» карточка товара и цвета находилась в скрытом разделе «Свойства», а из режима фокуса не возвращалась левая панель.

Теперь рамку можно выбрать кликом внутри контура, кликом по её розетке/выключателю в инструменте «Рамки» или через список «Рамка на плане» с поиском по помещению, цвету и товару. Карточка рамки открывается сразу в левой панели. Двойной клик ограничивает выделение одной физической рамкой и не захватывает одинаковые электроустановки других помещений. Ctrl + клик сохраняет возможность отдельного выделения электроустановок для переназначения рамок.

В карточке доступны товар, цвет без товара для группировки КП и отдельный «Цвет контура на плане». Контур действительно меняет цвет; оформление отдельных розеток сохраняется. Для обычных названий цветов, например «Белый» и «Чёрный матовый», доступен автоматический цвет контура. Светлые контуры имеют контрастную окантовку. Цвет применяется также в PDF плана.

Изменения сохраняются для всей рамки одним действием, поддерживают Ctrl+Z/повтор и ZIP-перенос. Цвет контура не дробит позиции КП: рамки объединяются по товару, а без товара — по названию цвета и числу постов. Сохраняются цены, скидки и намеренные исключения.

Проверка включает обычный клик, режим «Рамки», поиск по помещению, фокус на плане, уменьшенный масштаб, двойной клик, отсутствие сдвига объектов, назначение товара, цвет, Ctrl+Z, повторное открытие и PDF. Новый браузерный сценарий выполняется на собранных файлах приложения. Windows-сборка проверяет наличие редактора рамки и сохранение её свойств внутри автономного EXE.

Для обновления закройте приложение и запустите новый `SmartHomeCalc-Windows-x64.exe`. Схема базы не меняется. [Релиз v1.0.68](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.68) сохранён для отката.
