# Smart Home Calc v1.0.70

Проект возвращается на рабочий лист: запоминается страница последнего размещения или редактирования объекта. Если затем просто посмотреть другую страницу, при следующем открытии вернётся лист с последней работой. Для старых проектов без этой отметки используется лист последнего добавленного объекта; историю перемещений до обновления восстановить невозможно. Если объектов ещё нет, сохраняется прежний выбор просмотренной страницы.

Размер обозначений, видимость подписей объектов, названий и контуров помещений, адаптивные подписи, привязки и параметры инструментальных панелей сохраняются отдельно для каждого проекта. Настройки записываются в базу, входят в ZIP проекта и общую копию данных; на другом ПК они восстанавливаются вместе с проектом. Существующий браузерный кэш продолжает работать. При быстром закрытии используется более свежая локальная запись; устаревшая сетевая запись не заменяет новую. Масштаб и положение камеры каждого листа по-прежнему сохраняются локально.

В «Настройки → Резервная копия» добавлена кнопка **«Компактный ZIP для переноса»**. В ней уплотняется отдельная копия SQLite, применяется более сильное ZIP-сжатие и исключаются только известные уровни кэша PDF, для которых в архиве сохранены исходный PDF и базовое изображение. Товары, фотографии, КП, проекты и исходные планы сохраняются. Фотографии не перекодируются, действующая база и файлы не удаляются и не изменяются. Размер архива зависит от количества свободных страниц SQLite и накопленного кэша; каталог, состоящий преимущественно из фотографий, может уменьшиться незначительно.

Для переноса всего приложения создайте компактный ZIP, дождитесь его загрузки и скопируйте на другой ПК. Распакуйте архив и следуйте `Восстановление.txt` / `Restore-data.cmd`. Для переноса одного проекта используйте «Резервная копия» на плане: она включает используемые проектом товары и КП. Архивация товара скрывает его из выбора, но не уменьшает файл базы.

Сохраняются расстановка объектов, расчёты, миллиметры/метры, цены, скидки и Ctrl+Z. Оформление PDF КП не меняется.

Обновление добавляет два поля проекта; автономная Windows-версия обновляет существующую SQLite автоматически, серверная установка использует миграцию Alembic `014`. Для отката сохранён [релиз v1.0.69](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.69). Перед обновлением рекомендуется сохранить полный ZIP; приложение также сохраняет доступную предыдущую версию и её копию данных. Возврат на v1.0.69 не использует новые настройки из базы, но сохраняет существующие объекты и КП.
