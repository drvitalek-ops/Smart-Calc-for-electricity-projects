# Smart Home Calc v1.0.71

Исправлен разрыв между заполненными строками КП и товарами плана. Название, артикул, производитель, цена и фотография могли сохраняться только внутри КП: карточка в общей базе не создавалась, а свойства объекта показывали «Без привязки к товару».

После обновления приложение проверяет существующие проекты и восстанавливает однозначные связи для строк с заполненными названием, артикулом и производителем. Создаются общие карточки товаров с фотографиями. Уже существующий товар повторно используется по точному сочетанию производителя и артикула с проверкой единицы и номенклатуры. Цена существующего товара в каталоге не заменяется ценой из старого КП; цены, скидки и фотографии сохранённого КП остаются прежними.

В новых проектах при сохранении заполненных реквизитов строки КП создаётся карточка в общей базе и устанавливается связь с её существующими объектами плана. Это работает для точек, линейных объектов и рамок. Рамка получает собственный товар, отдельно от розеток и выключателей внутри неё. Номенклатура ручного товара остаётся необязательной. Дополнительные позиции, внесённые только в КП, сохраняются в базу без создания новых объектов на плане.

Если найдено несколько совместимых товаров с одним артикулом или слой заблокирован, приложение не выбирает случайный товар и не меняет защищённые объекты. В «Проверка КП → Связи товаров» показаны причина и переход к позиции. После уточнения товара или разблокировки слоя доступна кнопка **«Связать товары с базой и планом»**.

Восстановление связей плана отменяется одним Ctrl+Z. Артикулы, фотографии и текст КП при отмене сохраняются. После отмены перезапуск и обычное сохранение условий не привязывают тот же товар повторно; явная повторная привязка использует уже созданную карточку. Ошибка в одном старом КП не блокирует запуск приложения и открытие других проектов.

Обычное сохранение КП без новых реквизитов не загружает каталог заново. При поиске совпадений читаются идентификаторы и артикулы, без фотографий всех товаров.

Расстановка, длины в метрах, калибровка в миллиметрах, количество, ручные количества КП и оформление PDF не меняются. На предоставленном для диагностики проекте проверены 19 товаров, 50 объектов и 28 рамок; все три страницы PDF до и после восстановления совпали при сравнении растрового изображения. Личные данные проекта и сам архив в репозиторий не включены.

Обновление не требует изменения схемы базы. Перед автоматическим восстановлением связей используется штатная копия данных при обновлении. Предыдущий [релиз v1.0.70](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.70) сохранён для отката; компактный ZIP для переноса и настройки рабочего листа продолжают работать.
