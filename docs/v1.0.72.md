# Smart Home Calc v1.0.72

Исправлен выбор электроустановок внутри рамок. Раньше заливка рамки перехватывала клики рядом со значком. В режиме «Рамки» клик по устройству выбирал всю рамку, а повторный клик по электроустановке запускал групповое действие и мешал сразу начать перетаскивание.

Теперь клик по значку выбирает само устройство. Для электроустановки в существующей рамке открываются свойства объекта; двойной клик сохраняет индивидуальный выбор. Сразу после выбора можно перетащить именно это устройство. Зона нажатия вокруг значка немного расширена без изменения его видимого размера; при уменьшении масштаба остаётся удобный размер области нажатия.

Рамка выбирается явным действием: кликом по контуру, через список «Рамка на плане» или кнопкой **«Товар и цвет рамки»** в свойствах выбранной электроустановки. В инструменте «Рамки» свободная область внутри контура остаётся кликабельной. При обычном редактировании заливка рамки пропускает клики. Выбор рамки с клавиатуры Enter/Пробел сохраняется.

Быстрые Ctrl-клики переключают отдельные устройства, не запуская групповое действие двойного щелчка. После снятия выделения свойства показываются для оставшегося выбранного устройства. Контур рамки не подсвечивается как выбранная группа при обычном редактировании одного её элемента.

Проверены клики по краю значка, выбор из режима «Рамки», двойной клик, Ctrl-выделение, контур и клавиатура, уменьшенный масштаб, повторное открытие, немедленное перетаскивание одного устройства, правка его количества и Ctrl+Z. Состав рамок, привязки товаров, расчёты и оформление PDF сохраняются. Проверка перемещения подтверждает отсутствие лишних перерисовок статичной сцены.

Закройте приложение и запустите новый EXE. Схема базы не меняется. [Релиз v1.0.71](https://github.com/drvitalek-ops/Smart-Calc-for-electricity-projects/releases/tag/v1.0.71) сохранён для отката.
